01 · 전투와 탐험

세 영웅이 함께 움직이는 구조

자동 이동·공격, 직업별 스킬과 장비 전리품을 연결하고 던전 선택에서 전투 결과까지의 흐름을 구성했습니다.

02 · 마을과 성장

한 번 더 출정할 이유

인벤토리, 장비 강화, 영웅 성장, 룬 제작과 NPC 의뢰를 연결했습니다. 공통 경험치와 영웅별 강화를 분리했습니다.

03 · 데이터와 안정성

플레이 밖의 문제까지

테이블 가져오기, 저장 복구, 반복 씬 로딩, UI 팝업 순서와 Android 뒤로가기를 검증했습니다.

04 · Android 공개 체험판

설치해서 확인할 수 있는 결과물

서명 APK와 원격 콘텐츠 배포를 연결했습니다. 공개 체험판은 로그인과 실제 광고를 사용하지 않고 기기에 진행을 저장합니다.

게임 시스템·UI·데이터·빌드 흐름의 구현 포트폴리오입니다. 화면에는 외부 픽셀 아트·UI·폰트 리소스가 포함되어 있으며, 모든 원화를 직접 제작했다는 의미는 아닙니다. 전체 20스테이지와 모든 Android 기기에서의 완주 검증을 보장하지 않습니다.
